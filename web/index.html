Spotify API Tənzimləmələri

Spotify pleylistlərini yükləmək üçün şəxsi Spotify Developer tətbiqi açarlarınızı daxil etməlisiniz. Bu tamamilə pulsuzdur.

Açarları necə almaq olar?

  1. developer.spotify.com saytına daxil olun.
  2. Yeni tətbiq yaradın (Create an App).
  3. Client ID və Secret kodlarını bura daxil edin.
